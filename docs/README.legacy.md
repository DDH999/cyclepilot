## 1. 这套系统解决的真正问题

不是"缺一个回测工具"，是**缺一个能杀死坏策略的机制**。

市面上 99% 的量化系统会让你看到一个漂亮的 AUC / 夏普，然后亏钱。原因是泄漏和过拟合。
QuantPilot 的核心不是模型，是**门禁**。

### 实测结果（真实数据，非模拟）

A股 10 只 + 美股 4 只，2016-01 至今，34 个特征，Purged Walk-Forward：

| 任务 | AUC | 判定 |
|---|---|---|
| **波动率状态**（未来20日波动率是否高于250日中位） | **0.6835** ± 0.0799 | 接近但**未达** 0.70 门槛 |
| **日频涨跌方向** | **0.5220** ± 0.0094 | 诚实区间内，有微弱但稳定的边缘 |
| 洗牌标签对照 | **0.5067** | ✅ 通过（应≈0.50） |
| **随机切分对照（错误做法）** | **0.8556** | ⚠️ 凭空虚高 +17.2pp |
| 注入近似标签（泄漏检测器灵敏度） | 0.8915 | ✅ 检测器有效 |
| **PBO 过拟合概率**（8 个动量策略配置） | **0.754** | ❌ **拒绝部署** |

**两个必须说清的事实：**

1. **0.70 在日频方向上不可达。** 任何声称日频方向 AUC 0.7+ 的，先去查泄漏。
   本项目把 0.70 门槛放在波动率状态 / 事件风险 / 截面分组这些**真能到**的任务上。
2. **本项目自己写的动量策略族 PBO = 75%，被门禁拒绝。** 这是系统在工作，不是 bug。
   过拟合概率超过 50%，说明样本外表现不可复现。

## 2. 真实 A 股回测引擎（竞赛级）

**任何回测曲线，评委第一眼看的就是它有没有遵守 A 股交易规则。** 本引擎已实现：

| 规则 | 实现 |
|---|---|
| T+1 交收 | 当日买入次日才计入可卖数量 |
| 涨跌停 | 涨停禁买 / 跌停禁卖；创业板·科创板按 20%，主板 10% |
| 印花税 | 卖出 0.05%（2023-08-28 后标准） |
| 佣金 | 0.025%，单笔最低 5 元 |
| 过户费 | 0.001% 双向 |
| 滑点 | 可配置 bps（默认 5bps） |
| 最小手数 | 买入 100 股整数倍，卖出可零股 |
| 停牌/缺价 | 当日无成交则跳过 |
| 现金约束 | 不允许透支 |

**执行时序防未来函数**：信号在 T 日收盘产生 → T+1 日收盘成交。

### 全票池实测（1048 只 = 指数成分 795 + 退市 253，2016-01 ~ 2026-11）

> **注意**：以下数字是**并入退市股之后**的结果。加入退市股前，等权组合年化 13.4%；
> 加入后降到 4.4%——**那 9 个百分点就是幸存者偏差的规模**。

| 策略 | 全样本年化 | 全样本 Sharpe | 样本外年化 | 样本外 Sharpe | 最大回撤 |
|---|---|---|---|---|---|
| 多因子合成 +风控 | 14.5% | 0.90 | **-0.1%** | **0.07** | -25.4% |
| 动量 120-20 +风控 | 11.2% | 0.65 | 0.9% | 0.14 | -27.9% |
| 趋势 20/60 +风控 | 4.5% | 0.31 | -1.3% | -0.02 | -19.5% |
| 低波动 60 | 2.4% | 0.23 | 13.4% | 1.29 | -10.1% |
| **等权 14 策略集成** | **3.6%** | **0.41** | 0.7% | 0.13 | **-12.3%** |
| 基准：沪深300 | 15.8%（全期） | — | — | — | — |

**核心结论：修复幸存者偏差后，纯量价策略基本没有可靠的样本外 alpha。**
这是诚实的结果，不是失败——大多数公开的"A股动量策略年化 15%"都缺了这一步。

### 解法：换因子族，不是调参

在此基础上加入 **9 个基本面因子**（全部用「公告日期」做严格时点对齐）：

| 因子 | IC | 与动量相关性 | 全样本年化 | 样本外年化 | **样本外 Sharpe** |
|---|---|---|---|---|---|
| **盈利加速**（同比增速二阶） | -0.003 | **+0.01** | 8.8% | **11.4%** | **0.72** |
| 毛利率同比变化 | -0.009 | +0.00 | 6.3% | 5.8% | 0.45 |
| 净利润同比增速 | -0.013 | -0.03 | 5.9% | 5.4% | 0.41 |
| 营收同比增速 | -0.012 | -0.03 | 5.5% | 4.4% | 0.34 |
| 盈利收益率 (EPS/价格) | 0.036 | -0.16 | 4.0% | 3.0% | 0.31 |
| 账面收益率 (BPS/价格) | 0.043 | -0.16 | 8.5% | 0.9% | 0.13 |
| ROE | 0.005 | -0.02 | 2.7% | -2.2% | -0.12 |

**关键发现：基本面因子与动量的截面相关性接近 0**（盈利加速 0.01、毛利率变化 0.00），
是真正独立的信息，不是同一信号换个包装。

### 最终组合（基本面 + 动量）

| 指标 | 纯量价策略族 | **基本面+动量 合成** |
|---|---|---|
| 全样本年化 | 3.6% | **13.8%** |
| 全样本 Sharpe | 0.41 | **0.87** |
| 最大回撤 | -12.3% | -22.6% |
| **样本外年化** | 0.7% | **9.4%** |
| **样本外 Sharpe** | 0.13 | **0.65** |
| **PBO 过拟合概率** | 0.222 | **0.095** |
| **DSR 显著性** | 0.783 ❌ | **0.971 ✅** |

**这是本项目唯一通过全部检验的策略族。** IS 最优 = 全样本最优（无选择偏差迹象）。

**风控层的贡献仍然成立**（回撤维度）：

| | 裸策略 | +风控 | 改善 |
|---|---|---|---|
| 趋势 20/60 Sharpe | 0.68 | **0.97** | +0.29 |
| 趋势 20/60 回撤 | -47.5% | **-33.7%** | +13.8pp |
| 多因子 Sharpe | 0.75 | **0.95** | +0.20 |
| 多因子 回撤 | -44.7% | **-29.8%** | +14.9pp |

**换手缓冲带**（持仓跌出 top_n×(1+0.5) 才卖）：把年换手从 400%+ 降到 100~300%，
在不牺牲收益的前提下大幅降低交易成本。

### ⚠️ 必须主动声明的偏差

1. **幸存者偏差（最重要）**：票池用的是**当前**中证800 成分股，等于只交易了活下来并做大的公司。
   绝对收益偏乐观。**策略之间的相对排序仍然有效**（所有策略承受同一偏差），但不要相信 21.5% 这个绝对数字。
   彻底修正需要 point-in-time 成分股历史，akshare 无此接口。
2. **单一市场单一周期**：仅 A 股、仅 2016-2026，覆盖了一轮半牛熊，不足以证明跨周期稳健。
3. **无行业中性化**：策略可能隐含行业押注。生产环境应做行业暴露约束。
4. **容量未测算**：Top30 等权在 795 只大盘中盘股上容量尚可，但未做冲击成本建模。

## 3. 诚实检验：你的好成绩是真的吗

竞赛评委第二个必问的问题：**"你试了多少次才挑出这个？"**

`python backend/validate.py` 做三重检验：

| 检验 | 结果 | 判定 |
|---|---|---|
| **PBO 过拟合概率**（CSCV, 10 blocks, 252 组合） | **0.234** | ✅ 通过（<0.50）：策略族整体可复现 |
| **Deflated Sharpe**（对 14 次尝试惩罚） | **0.963** | ✅ 显著（>0.95） |
| **IS→OOS 排名相关 ρ** | **+0.147** | ❌ 接近 0：**样本内挑优对未来没有预测力** |

### 最关键的一张表：样本内选优 → 样本外验证

| 策略 | IS 年化 | IS Sharpe | OOS 年化 | OOS Sharpe | 衰减 |
|---|---|---|---|---|---|
| 多因子合成 +风控（**IS 最优**） | 15.9% | 1.10 | 6.7% | **0.46** | **-0.63** |
| 趋势 20/60 +风控 | 16.6% | 0.92 | 20.6% | 0.90 | -0.02 |
| 动量 250-20 +风控 | 14.8% | 0.96 | 9.9% | 0.56 | -0.40 |
| 动量 120-20 +风控 | 13.5% | 0.84 | 6.3% | 0.40 | -0.44 |

**必须读懂这一点：**

1. **样本内最好的（多因子 1.10）到样本外只剩 0.46，腰斩还多。** 这就是过拟合的标准形态。
2. 13 个策略里 9 个衰减为负。**说明"在历史上挑最好的那个"这套方法论本身没有预测力**（ρ=0.15）。
3. **"趋势 20/60 +风控" OOS 0.90 看着很美，但它是我用全样本数据挑出来的**——它的 OOS 数字已经被选择行为污染，**不算真正的样本外证据**。诚实地说，它可能是运气。

### 所以真实的预期收益是多少？

| 方案 | 全样本 Sharpe | **干净 OOS Sharpe** | 干净 OOS 年化 | 干净 OOS 回撤 |
|---|---|---|---|---|
| IS 选优（诚实流程） | — | **0.46** | 6.7% | -19.4% |
| **等权 14 策略集成**（规则固定，无选择偏差） | 0.69 | **0.62** | **9.8%** | **-20.0%** |
| 趋势 20/60+风控（全样本最优，**数字被污染**） | 0.91 | (0.90 不可信) | — | — |

> **对竞赛/实盘应该按 0.5~0.6 的 Sharpe、约 10% 年化、约 -20% 回撤来做预算。**
> 不是 0.91，不是 21%。
>
> 等权集成是这个项目里**最经得起追问的提交方案**：它的规则是固定的（不选优），
> 所以它的样本外表现是干净的。

## 4. 怎么用（人话版）

### 只想看结果
```bash
python backend/app.py        # 打开 http://127.0.0.1:8420
```
界面上四块：**门禁判定 / 策略回测 / 诚实检验 / 实时监控**。先看"诚实检验"，那是唯一说真话的地方。

### 想改参数重跑
```bash
# 更保守（降回撤）：止损收紧、行业更分散、仓位更低
python backend/run_strategy.py --top 20 --vt 0.10 --stop-loss 0.10 --max-per-ind 2 --save

# 每改一次参数，必须重跑验证，否则你就是在过拟合
python backend/validate.py
```

### 三个数字怎么看
- **Sharpe**：每承担 1 单位波动赚多少。**赛场上 0.6 就不错了，1.0 以上先怀疑过拟合。**
- **最大回撤**：最难看的那个数字。评委和出资人最先看这个。**竞赛通常要求 <25%。**
- **PBO**：越小越好。<0.5 说明你的策略族不是碰巧。

### 参赛提交清单（按评委会问的顺序）
1. 策略逻辑一句话讲清（趋势跟随 + 波动率目标 + 市场状态过滤 + 行业中性）
2. 回测规则声明（T+1、涨跌停、印花税 0.05%、佣金、滑点、100 手）
3. **样本外结果**（用 2023 以后，别用 2016-2026 全样本）
4. **PBO 与 DSR**（证明不是挑出来的）
5. 偏差声明（幸存者偏差、单市场周期、无冲击成本）
6. 风控参数与触发条件

## 4. 关键模块

### 4.1 评估门禁 `evals.py`

```python
from evals import purged_walk_forward, evaluate, leakage_audit, pbo_cscv, deflated_sharpe

# 清洗式时间序列切分（训练标签窗口不得跨入测试区）
for tr, te in purged_walk_forward(n=5000, n_folds=6, horizon=20):
    ...

# 泄漏审计三对照
leakage_audit(df, task="y_vol_regime")
#  -> random_split_auc / purged_wf_auc / shuffled_label_auc / leak_injected_auc
```

**四条铁律：**
1. 特征只用 t 及之前；标签用 t+1..t+h
2. 时间序列 walk-forward + purge，禁止随机切分
3. 洗牌标签必须回落 0.5 附近
4. 多重检验惩罚（PBO / DSR）不过关就不许上钱

### 4.4 多智能体研究编排

`/api/research` 代理到 Vibe 的 `/swarm/runs`。实测可用的预设（对应你要的三专家辩论）：

| 预设 | 结构 | 用途 |
|---|---|---|
| `investment_committee` | 多空辩论 → 风控复核 → PM 裁决 | **个股深度决策** |
| `sector_rotation_team` | 周期 + 景气 + 资金流 → 轮动策略 | **赛道周期定位** |
| `geopolitical_war_room` | 地缘 + 能源 + 供应链 → 首席策略官 | 地缘冲击（霍尔木兹/红海） |
| `fundamental_research_team` | 财务 + 估值 + 质量 → 编辑 | 基本面深度报告 |
| `risk_committee` | 回撤 + 尾部 + 状态 → 风控长 | 组合风险审计 |

**重要坑**：不同预设给 agent 的工具权限不同。实测 `sector_rotation_team` 中
`cycle_analyst` / `prosperity_analyst` **没有数据工具**，产出会退化成"方向性判断，不引用数字"。
要数字必须走 `investment_committee` / `earnings_research_desk`（这两个实测有 `get_market_data`）。

## 8. 已知局限（诚实清单）

1. **幸存者偏差未解决。** 票池为当前指数成分，绝对收益偏乐观（详见第 2 节偏差声明）。
2. **样本外 Sharpe 只有 0.46~0.62。** 全样本 0.91 是选择污染的产物。按 0.5~0.6 做预算。
3. **IS→OOS 排名相关仅 +0.147。** 意味着策略选择方法论本身不可靠；等权集成比择优选更稳。
4. **样本外只有 2023-2026 约 3 年**，覆盖不了完整牛熊，OOS Sharpe 的置信区间很宽。
5. **样本内 AUC 0.6835 未达 0.70**（模型侧），门禁如实拒绝，不影响策略侧回测。
6. **PBO = 0.234 是"策略族"整体指标**，不等于每个策略都可用；衰减为负的 9 个策略应剔除。
7. **回撤最差 -26.8%（趋势+风控）**，若竞赛要求 <25% 需再收紧止损或降低目标波动。
8. **美股数据源复权不可靠**，已用 `repair_splits()` 兜底，但不保证 100% 正确。
9. **回测策略尚未做容量/冲击成本测算。** Top30 在 795 只大盘中盘上容量尚可，但未建模。
10. **未实现**：万字研报自动生成、真实资金交易、定时调度、point-in-time 成分股、行业暴露精确约束（当前只做数量上限）。
11. **未验证**：推送三通道均为 DRY_RUN 演练，未配置真实凭证实测。
