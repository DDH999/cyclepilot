# QuantPilot 本地部署手册

> 结论先说：**这套系统本来就是纯本地的**——没有服务器、没有数据库、没有云服务。
> 数据存在你自己电脑的文件夹里，页面跑在 `127.0.0.1`，只有你能访问。
> 本文解决的是「怎么让它稳定地长期跑」。

---

## 一、前置条件

| 项 | 要求 | 检查命令 |
|---|---|---|
| 操作系统 | Windows 10/11（实测 Win11） | — |
| Python | 3.10+（实测 3.14.3） | `python --version` |
| 磁盘 | 代码 < 5 MB，缓存会涨（见第六节） | — |
| 网络 | 能访问 akshare 数据源（东财/新浪/百度） | 首次启动会自动验证 |

依赖已锁定在 `requirements.txt`（8 个包，精确版本号）。

---

## 二、三种启动方式

### 方式 1：一键（推荐）

双击 **`start.bat`**

它会依次做四件事：

```
[1/4] 检查 Python
[2/4] 检查依赖（缺了自动装）
[3/4] 运行自检（132 项 → 全绿才继续）
[4/4] 启动服务并打开浏览器
```

**自检不通过会中止启动**，不会带着病跑。

### 方式 2：命令行

```powershell
cd quantpilot
python backend/preflight.py          # 先自检
python backend/quantpilot.py serve   # 启动
```

想换端口：

```powershell
python backend/quantpilot.py serve --port 9000
```

### 方式 3：开机自启（可选）

1. 打开「任务计划程序」
2. 创建任务 → 触发器「登录时」→ 操作「启动程序」
3. 程序：`C:\Windows\System32\cmd.exe`
4. 参数：`/c "cd /d <你的路径>\quantpilot && python backend\api_v2.py"`
5. 勾选「不管用户是否登录都要运行」看需求

**不建议**做成 Windows 服务（需要额外工具，收益不大）。

## 三、停止服务

- 双击 **`stop.bat`**（按端口找进程并结束）
- 或直接关掉启动时的命令行窗口

## 四、数据在哪里

```
quantpilot/
├── holdings.csv          你的持仓（手填，重要）
├── dca_ledger.csv        你的定投记录（手填，重要）
├── watchlist.txt         自选股（日更用）
├── reports/              净值、日更报告、图表
├── .state/risk_state.json 风控决策历史（闭环用）
├── .cache/               行情缓存（可删，见第六节）
└── logs/quantpilot.log   运行日志
```

**只有三个文件是你手填的、丢了要重来：**
`holdings.csv`、`dca_ledger.csv`、`watchlist.txt`

其余（reports/.state/.cache）都能重新生成。

## 五、备份

双击 **`backup.bat`**，会按日期建目录并把关键数据复制进去：

```
backups/20261112_2130/
├── reports/
├── .state/
├── holdings.csv
├── dca_ledger.csv
└── watchlist.txt
```

建议每周一次。也可以把这个目录同步到网盘。

## 六、缓存治理（重要）

缓存会持续增长。实测本机 10 天累积到 **1.1 GB**：

| 类别 | 文件数 | 体积 |
|---|---|---|
| 行情 CSV | 2150 | 591 MB |
| panel 缓存 | 2 | 424 MB |
| 基金净值 | 54 | 52 MB |

### 查看

```powershell
python backend/quantpilot.py cache
```

### 清理（默认干跑，不会真删）

```powershell
python backend/quantpilot.py cache --trim 30        # 看会删什么
python backend/quantpilot.py cache --trim 30 --yes  # 真删 30 天未用的
python backend/quantpilot.py cache --clean          # 清空全部（看清单）
python backend/quantpilot.py cache --clean --yes    # 真清空
```

**安全保证**：只在 `.cache/` 内操作，绝不碰 `reports/`、`.state/`、持仓台账。

清空缓存后第一次取数会变慢，但功能不受影响。

## 七、日常怎么用

| 频率 | 命令 | 干什么 |
|---|---|---|
| 每天 | `python backend/quantpilot.py risk` | 风控决策 + 记账（形成闭环） |
| 每天 | `python backend/quantpilot.py daily` | 拉行情、更新净值 |
| 每周 | 双击 `backup.bat` | 备份 |
| 每月 | `python backend/quantpilot.py cache --trim 30 --yes` | 清缓存 |
| 想看全局 | `python backend/quantpilot.py status` | 一屏状态 |

## 八、常见问题

### 端口被占用

```
ERROR: [Errno 10048] error while attempting to bind on address ('127.0.0.1', 8421)
```

解决：双击 `stop.bat`，或换端口 `serve --port 9000`。

### 依赖装不上

国内网络用镜像：

```powershell
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 取数失败 / 数据源挂了

系统有多源降级（东财 → 新浪）。查看健康状态：

```http
GET http://127.0.0.1:8421/api/sources
```

常见原因：
- 网络断
- 东财接口临时维护（会自动降级到新浪，只是慢一点）
- 熔断中（连续失败 3 次后冷却 300 秒，等一会儿自动恢复）

### 页面打开是空白

1. 看 `logs/quantpilot.log`
2. 确认 `python backend/preflight.py` 全绿
3. 浏览器按 `Ctrl+F5` 强制刷新（前端可能有缓存）

### 想搬到另一台电脑

复制整个 `quantpilot` 目录（**可以不复制 `.cache` 和 `backups`**），
在新机器上跑一次 `install.bat`，然后 `start.bat`。

## 九、安全边界（务必看清）

| 项 | 现状 |
|---|---|
| 监听地址 | `127.0.0.1`（仅本机） |
| 鉴权 | **无** |
| 用户体系 | **无**（单用户） |
| 数据库 | **无**（文件存储） |
| 用户代码执行 | `exec` 在**同一进程**，不沙箱 |

**结论：只能在自己电脑上用。**

绝对不要把端口映射到公网、不要用 `0.0.0.0` 监听、不要部署到有他人访问的服务器。

「代码体检」功能会执行你输入的 Python 代码——**只运行你自己写的或你信任的代码**。
