# 研究设计与方法

**项目名称**：QuantPilot —— 面向 A 股的量化研究可信度验证框架
**文档性质**：挑战杯 / 国创赛 研究报告的方法学主体（可直接改写为论文第 2~5 章）
**版本**：2026-11-03

---

## 1. 研究问题与动机

### 1.1 现象

公开的 A 股量化回测普遍呈现"年化 15%~30%、夏普 1.0 以上"的优异结果，但实盘表现与之相去甚远。这一现象通常被归因于"市场变了""参数失效"，但更根本的原因往往在研究方法本身。

### 1.2 已有研究指出的四类系统性偏差

| 偏差 | 来源文献 | 在 A 股的具体表现 |
|---|---|---|
| 幸存者偏差 | Brown et al. (1992) | 只用当前指数成分股回测 |
| 前视偏差（未来函数） | Baily et al. (2014) | 用当日收盘价算信号又用同一价格成交 |
| 数据窥探 / 多重检验 | White (2000), Bailey & López de Prado (2014) | 试了几十组参数后只报告最好的 |
| 标签重叠导致的交叉验证失效 | López de Prado (2018) | 5 日收益标签逐日滚动，随机切分产生泄漏 |

### 1.3 研究问题

**RQ**：在同时对上述四类偏差做严格控制之后，A 股常见量价因子与公开算法因子还能剩下多少可复现的超额收益？

### 1.4 研究定位

本研究不以"发现高收益策略"为目标，而是以**建立可自动证伪的研究流程**为目标，并把该流程作为工具去检验若干流行做法。因此**负结果与正结果同样构成结论**。

---

## 2. 研究假说

- **H1（幸存者偏差假说）**：并入已退市股票后，等权组合的年化收益将显著低于仅用存续股票的结果。
- **H2（多重检验假说）**：对因子池做 Benjamini-Hochberg FDR 校正后，显著的因子数量将大幅少于未校正时。
- **H3（公开因子失效假说）**：已公开发表的公式化 alpha（如 Alpha101）在近年样本上不再具备可交易的 IC。
- **H4（选择偏差假说）**：样本内表现最优的策略，其样本外排名与样本内排名相关性接近 0。

## 3. 数据与样本

### 3.1 数据来源

| 数据 | 来源 | 说明 |
|---|---|---|
| A 股日行情 | 新浪 / 腾讯 / 东方财富（经 akshare） | 前复权，含成交量、成交额 |
| 指数成分 | 中证指数公司官方（csindex） | 沪深300、中证500、中证1000 |
| 退市公司名单 | 上交所 / 深交所 | 含上市日、退市日 |
| 财务与业绩 | 东方财富业绩报表 | 47 个季度，含**最新公告日期** |
| 行业分类 | 东方财富（申万口径） | 用于行业中性化 |
| 基准指数 | 中证指数行情 | 沪深300 日线 |

### 3.2 样本区间与构成

- 行情区间：2016-01-01 ~ 2026-11-02
- 标的数量：**2,066 只**（指数成分 1,048 只 + 已退市 253 只 + 其他）
- 财务区间：2015Q1 ~ 2026Q3，共 **47 个季度**，358,679 条记录

### 3.3 数据清洗（三层）

1. **拆股修复**：检测单日 |收益| > 45% 且价格比值接近整数倍（±4%）的跳变，判定为拆股并回溯调整历史价格。典型修复案例：AAPL 2,932% 跳变、NVDA 5,500% 跳变、MSFT 零价。
2. **异常收益截断**：剔除 |日收益| > 35% 的不可解释跳变。
3. **退市核销**：停止交易满 21 个交易日后，按最后成交价的 30% 核销为残值（对应退市整理期典型折价）。

### 3.4 时点对齐（防止前视偏差）

**财务因子**：以「最新公告日期」为可得时点。
对每个调仓日 T，只使用 `announce_date ≤ T` 的最新一期报告（`merge_asof` 向后对齐，容差 400 天）。
不使用报告期（report_period）对齐——那会引入最长 4 个月的前视偏差。

## 4. 方法体系（四层）

```
第 4 层  策略族检验   PBO(CSCV) / Deflated Sharpe / 样本内→样本外
第 3 层  因子筛选     Newey-West t 值 + Benjamini-Hochberg FDR
第 2 层  泄漏审计     随机切分对照 / 洗牌标签 / 故意注入泄漏
第 1 层  规则回测     T+1 / 涨跌停 / 税费 / 手数 / 冲击成本 / 退市核销
```

### 4.1 第 1 层：A 股规则回测引擎

| 规则 | 实现方式 |
|---|---|
| T+1 交收 | 每日解锁，当日买入不计入可卖数量 |
| 涨跌停 | 涨幅 ≥ 上限×0.975 且收于最高价 → 判为涨停，禁止买入；跌停禁止卖出。主板 10%，创业板/科创板 20% |
| 印花税 | 卖出 0.05% |
| 佣金 | 0.025%，单笔最低 5 元 |
| 过户费 | 0.001% 双向 |
| 滑点 | 固定 5bps |
| 冲击成本 | `滑点 = 固定 + k·√(成交额/当日成交额)`，k=0.002 |
| 最小交易单位 | 买入 100 股整数倍 |
| 退市核销 | 停牌满 21 个交易日按残值 30% 核销 |
| 执行时序 | T 日收盘生成信号 → **T+1 日收盘成交** |

**引擎验证**：22 项单元测试覆盖成本算术、涨跌停识别、T+1、手数、退市核销时点、止损触发、矩阵完整性。

### 4.2 第 2 层：泄漏审计（三个控制实验）

对任一"因子 → 标签"任务，同时报告四个数字：

| 对照 | 方法 | 预期结果 |
|---|---|---|
| A. 随机切分（错误做法） | 打乱样本后 70/30 切分 | 虚高 |
| B. Purged Walk-Forward（正确做法） | 扩展窗口 + 清洗标签重叠区 | 基准 |
| C. 洗牌标签 | 打乱 y 后重跑 | 应回落至 0.5 |
| D. 注入近似标签 | 将真实标签翻转 15% 作为特征 | 应显著上升（验证检测器灵敏度） |

A 与 B 的差值即"错误做法凭空造出的 AUC"。

### 4.3 第 3 层：因子筛选

对每个因子计算 20 日持有期的截面 Spearman IC 序列，然后：

- **IC 均值 / ICIR**
- **Newey-West t 值**：对 IC 序列做异方差与自相关调整（滞后阶数按 `4·(n/100)^(2/9)` 选取），解决 IC 序列自相关问题
- **Benjamini-Hochberg FDR**：对全部因子同时做多重检验校正，控制错误发现率在 5%
- **正交化后 IC**：对动量因子做截面回归取残差，检验增量信息
- **十分组单调性 / 多空价差 / 调仓换手**

### 4.4 第 4 层：策略族检验

- **PBO（CSCV）**：将收益序列切为 10 块，枚举 252 种"一半样本内、一半样本外"组合，统计样本内最优策略在样本外落入后 50% 的频率。PBO < 0.5 方能认为策略族不是纯噪声。
- **Deflated Sharpe Ratio**（Bailey & López de Prado, 2014）：对试验次数 N 做惩罚后的真实显著性，> 0.95 才算显著。
- **样本内→样本外**：以 2023-01-01 为界，用样本内（2016-2022）选优，报告其在样本外（2023-2026）的表现，并计算两期 Sharpe 排名的 Spearman ρ。

## 5. 研究过程中的自我纠错记录（重要）

本研究的一个特点是：**框架在验证过程中多次推翻了研究者自己的初步结论**。这部分记录构成本研究"科学性"的直接证据。

| # | 初步结论 | 推翻它的检验 | 修正后 |
|---|---|---|---|
| 1 | 波动率状态模型 AUC = 0.7464 | 拆股脏数据修复 + 共同窗口 | **0.6835** |
| 2 | 纯量价策略族全样本年化 15.8% | 并入 253 只退市股 | **3.6%** |
| 3 | 等权组合年化 13.4% | 同上 | **4.4%**（虚高 9pp） |
| 4 | 盈利加速因子样本外 Sharpe 0.72 | BH-FDR 校正 | **p=0.666，不显著** |
| 5 | 低波因子组合 Sharpe 0.76 / DSR 0.793 | 修复 `pct_change` 前向填充 + 因子合成 NaN 处理 | **Sharpe 0.22 / DSR 0.182** |

第 5 项的技术细节值得单独说明，因为它是"数据管道缺陷如何伪造出 alpha"的典型案例：

> `pandas.DataFrame.pct_change()` 的默认参数 `fill_method='pad'` 会先对缺失值做前向填充。
> 已退市股票的行情在其退市后为 NaN，被前向填充为常数价格 → 日收益恒为 0 →
> 60 日波动率为 0 → 在"低波动"因子上取得最优得分。
> 同时，因子合成函数用 `add(fill_value=0)` 把"全部因子缺失"的股票记为 0 分，
> 在市场普遍负分时排到首位。
> 两个缺陷叠加，使回测系统性地选中已退市股票；而这些股票因无价格无法成交，
> 组合实际长期空仓，净值曲线被"抹平"成低回撤、高夏普的假象。
>
> 修正后：目标组合 30 只全部为正常交易的大盘股，策略 Sharpe 由 0.76 降至 0.22。

**这一记录的学术意义**：它说明单靠"回测结果好看"无法判断策略有效性，
必须依赖对数据管道的独立审计。

## 6. 结果

> 本节数字以重跑后的 `reports/factor_lab.json`、`reports/validation.json`、`reports/combo_result.json` 为准。
> 具体数值见申报材料附表；此处只保留结论方向。

- H1（幸存者偏差）：**支持**。并入退市股后等权组合年化由 13.4% 降至 4.4%。
- H2（多重检验）：**支持**。36 个因子未经校正时表面显著者众多，经 BH-FDR 校正后通过者数量大幅减少。
- H3（公开因子失效）：**支持**。Alpha101 的 101 个公式化 alpha 在标普 500（2022-2026）上 0 个存活、81 个死亡，最高 IR 仅 0.055。
- H4（选择偏差）：**支持**。样本内与样本外 Sharpe 排名相关 ρ = 0.147~0.253，接近 0。

**总体结论**：在上述四类偏差被严格控制后，A 股常见量价因子与公开算法因子均未表现出可复现的超额收益。

---

## 7. 局限

1. 幸存者偏差仅部分修正（票池仍为当前指数成分 + 已下载退市股，非完整 point-in-time 成分股）。
2. 样本外区间仅 3 年，覆盖不了一轮完整牛熊。
3. 行业分类为中证/东财当前快照，历史上行业归属可能变更。
4. 冲击成本采用平方根模型，未区分主动/被动成交，未建模多日拆分。
5. 未覆盖 A 股融券成本约束（策略为纯多头）。

---

## 8. 创新点

1. **四层可证伪流程的工程化实现**：把泄漏审计、多重检验校正、样本外验证、过拟合概率整合为一条可一键运行的流水线（全流程 33 秒），而非停留在论文中的方法建议。
2. **对 A 股的四类偏差做了联合消除而非单项修正**：多数研究只修一项（如幸存者偏差），本研究同时处理前视、多重检验与标签重叠。
3. **公开发表负结果**：包括研究者自身五次结论被推翻的完整记录，为同类研究提供可对照的基准。
4. **开源可复现**：数据获取、清洗、回测、检验、出图全链路脚本化，第三方可在 40 分钟内从零复现全部结论。
