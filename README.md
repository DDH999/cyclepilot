# QuantPilot

> **我造了一台能证伪自己的量化研究系统。**
> 它最终告诉我：我的选股策略打不过什么都不做。

---

## 结论先行

| | 年化 |
|---|---|
| 低波动选股策略（严格样本外） | **+6.55%** |
| 什么都不做（等权持有全市场） | **+15.22%** |
| **超额** | **−8.67pp** |

> 不同抽样与窗口下，超额在 **−4.65pp ~ −8.67pp** 之间波动。
> 方向一致：**没有正 alpha。**

**本项目最大的产出不是收益，是一套能识别「回测自欺」的方法。**

---

## 为什么值得看

市面上 90% 的量化项目死于同一件事：**回测很美，实盘很惨**。

原因不是策略不够聪明，而是回测里藏着偏差。本项目把它们逐个挖出来，并**量化每一层偏差值多少钱**：

| 偏差 | 影响 |
|---|---|
| 用**当前成分股**回溯历史（幸存者偏差） | 虚高 **17.69pp** |
| 基准用沪深300，而非**同池等权** | 虚高 **16.96pp** |
| 用**前复权**处理长历史 | 早期价格变负（AAPL 1984 年 = **−10.75**） |
| 组合长期空仓，却被读成「低波动」 | 年化波动仅 **1.3%**（假的） |

**每剥掉一层乐观偏差，超额就往下掉一块。** 这是本项目最核心的发现。

## 它做了什么

### 数据层

- **5,824 只 A 股 / 8,858,364 行日线**（2019–2026）
- 多源取数（Tushare / baostock / efinance / adata / akshare / zzshare），自动降级 + 熔断
- Parquet 长表存储（按年分区），**读取时复权**——彻底避免前复权负价
- **时点票池**：上市日 / 退市日 / 60 交易日次新过滤，逐日构建可交易全集
- 10 项数据质量检查（致命 / 严重 / 一般三级）

### 研究层

- **严格回测引擎**
  - T+1 执行（信号次日开盘成交）
  - 逐日 ST 涨跌停判定（5% / 20% / 30%）
  - 停牌、涨跌停不可成交
  - 五类成本：佣金 / 印花 / 过户 / 滑点 / 冲击
  - **单日成交额 5% 流动性约束**
  - **分档退市核销**（连续跌停→全额损失；否则按整理期均价封顶最后收盘）
- **参数级 Walk-forward**：每折 IS 选参 → 紧邻 OOS 验证，绝不回头
- 版本管理：策略/因子代码入库、乐观锁、运行归档、版本 diff

### 风控层

- 风险预算：波动率目标 / 逆波动加权 / **ERC 等风险贡献**
- 事前风控：单票 / 行业 / 杠杆 / 换手上限
- 事中风控：回撤熔断 + 冷却
- 事后归因：单票 / 行业 / 时间 / Brinson / 归因对平检查

### 运维层

- 全链路审计日志（JSONL，可查可汇总）
- 轻量调度（依赖 / 重试 / 幂等 / 锁）
- 健康检查 6 项 + 告警签名去重
- 备份 / 校验 / 恢复
- 日更流水线：入库 → 体检 → 研究 → 日报 → 推送
- 多渠推送：邮件 / 飞书 / 企业微信 / **个人微信（Server酱）**

### 工程质量

- **2,600+ 项自动化测试**
- 全链路可追溯：从「某只股票某天的价格」到「报告里某个数字」
- 一键自检：`python backend/preflight.py`

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置（复制示例并填自己的）
cp config/mail.local.example.json     config/mail.local.json
cp config/notify.local.example.json   config/notify.local.json

# 3. 配置 Tushare token
export TUSHARE_TOKEN=你的token

# 4. 灌数据（按交易日拉全市场，可断点续传）
python backend/tushare_bulk.py --start 20240101 --batch 300

# 5. 跑检验（含自动等权对照）
python backend/param_walkforward.py --codes 500
```

## 踩过的坑（最有价值的部分）

详见 [`docs/PITFALLS.md`](docs/PITFALLS.md)。摘要：

1. **前复权在长历史上会产生负价** —— 累计分红超过早期股价
2. **空仓看起来像低波动** —— 投资率 30% 的组合，净值会像债券
3. **进度标记跑在落盘之前** —— 崩溃后这些日期被永久跳过
4. **用当前成分股回溯** —— 选了「活到今天的赢家」
5. **基准选错** —— 沪深300 vs 同池等权，差 17pp
6. **限流被误判为无权限** —— 永久禁用了一个可用数据源

## 这个项目适合谁

| 你是 | 能学到 |
|---|---|
| 量化初学者 | 什么叫做对的研究，以及为什么要对自己苛刻 |
| 数据工程师 | 时点数据、复权、断点续传的工程实践 |
| 个人投资者 | 为什么「回测很美」通常意味着「哪里骗了自己」 |

**它不适合**：想找「稳赚策略」的人。它只会告诉你「大概率没有」。

## 已知局限

- 单一市场（A股）、单一资产（股票）、日频

- 样本 2019–2026，只经历一次风格切换，统计功效有限
